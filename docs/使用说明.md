# 拾图 使用说明

> **分类**（左侧栏）和**标签**是两套东西：分类决定图片放在哪个文件夹视图里；标签只用于在分类内进一步筛选。

## 1. 首次启动

1. 打开软件，看到「欢迎使用 PickPic」。
2. 选择存储目录（默认在 `图片\PickPic`，也可以点「浏览」选别的位置，例如 `D:\PickPic`）。
3. 点「开始使用」。

之后所有图片、缩略图和索引都会保存在这个目录里。想换地方：设置 → 存储 → 修改（会把现有图库完整迁移过去，旧目录保留）。

## 2. 导入图片

- 从资源管理器把图片（或文件夹）拖进窗口，窗口出现蓝色虚线高亮后松手。
- 支持格式：jpg / jpeg / png / gif / webp / bmp / svg / avif。
- 默认**移动**：原文件会从原位置消失，进入图库。想保留原文件：设置 → 行为 → 拖入图片时选「复制」。
- **重复检测**：如果拖入的图片与库内某张内容完全一致，会先弹出「发现重复图片」，可选择「跳过重复（推荐）」或「仍然添加」；确认后才进入命名框。
- **命名框**：
  - **分类**：可选「未分类」、已有分类，或「＋ 新建分类…」。在哪个分类页拖入，就默认选哪个分类；在「全部图片」「未分类」页拖入则默认「未分类」。
  - **标签**：可选「不添加标签」、已有标签，或「＋ 新建标签…」；默认选中上一次使用的标签，批量导入时自动与上一张同步。选中标签后文件名自动为「标签_图片名」。
  - 输入图片名，回车确认；`Esc` 跳过这一张（文件留在原处），「全部取消」结束整个队列。
  - 非法字符自动变成下划线，重名自动加 `_1`、`_2`。
- 拖入文件夹时会先询问：可以「批量导入」（沿用原文件名）或「逐个命名」。
- 拖入非图片文件会明确提示被拒绝的文件名与原因。

## 3. 浏览、选择与筛选

- 缩略图网格：右上角可切换「小 / 中 / 大」。
- 顶栏「排序」支持：文件名（自然排序，图2 在 图10 前）、文件大小、修改时间、导入时间、图片类型；旁边的箭头切换升序/降序，选择自动记住。
- **按标签筛选**：顶栏「标签」下拉，默认「不筛选」；选择一个标签后只显示当前分类里带该标签的图片。关闭软件再打开会回到「不筛选」。
- 双击缩略图打开大图预览：`Esc` 关闭，`←` / `→` 切换。
- 选择方式：
  - 单击选中一张；**再单击已选中的图片会取消选择**（双击仍是打开预览）；
  - `Ctrl + 单击` 加选/取消；
  - **按住 Ctrl 拖动鼠标滑过图片**：经过的图片逐个切换选中状态（已选的会被取消）；
  - 松开 Ctrl 后，按住任意一张已选图片拖动，即可整组拖出；
  - `Ctrl + A` 全选，`Space` 选中/取消当前焦点，方向键移动焦点。

## 4. 删除图片

- 右键图片 →「删除图片」（多选时显示「删除选中的 N 张」）。
- 选中后按 `Delete`，或点底部批量栏的「删除」。
- 会弹出确认框，确认后**永久删除原文件与图库记录**，无法恢复。
- 只想「移出图库但保留文件」时，请用拖出（设置里切「移动」），不要用删除。

## 5. 拖出使用

- 在缩略图上按住并拖到外部（桌面、微信、PS、文件夹），目标会收到真实文件。
- 默认**复制**：库内保留。
- 设置 → 行为 → 拖出图片时选「移动」：拖出成功后该图从库中移除。
- 拖出时会有半透明缩略图跟随光标，并显示「拖出 N 张」；拖回图库目录会被自动撤销并提示。

## 6. 分类与标签

**分类**（左侧栏）：

- 「新建分类」创建；分类右键可新建 / 重命名 / 删除。
- 归类方式：右键图片「归入…」、把图片拖到左侧分类、多选后「归类到 ▾」、或命名导入时选择分类。
- 分类只是逻辑标记，**不会移动文件**。删除分类只解除关联，图片仍在「全部图片」里。
- 「未分类」显示还没有任何分类的图片。

**标签**（用于筛选）：

- 给图片打标签：右键图片 →「标签…」，勾选已有标签或输入新标签；批量选中后点底部「标签」按钮同样可以。
- 标签不会改变图片所在的分类；一个标签可以打给多张图片，一张图也可以有多个标签。
- 顶部「标签」下拉可按标签筛选，默认「不筛选」，重启后自动回到不筛选。

## 7. 快捷键

默认快捷键（设置 → 快捷键 里可以改）：

| 操作 | 默认按键 | 生效范围 |
| --- | --- | --- |
| 预览选中图片 | `Enter` | 网格 |
| 选中 / 取消选中 | `空格` | 网格 |
| 全选 | `Ctrl + A` | 网格（当前分类内） |
| 删除选中图片 | `Delete` | 全局（输入框内不触发） |
| 打开设置 | `Ctrl + ,` | 全局 |
| 预览上一张 / 下一张 | `←` / `→` | 大图预览 |

- 设置 → 快捷键：点右侧按键按钮，直接按下新的组合键即可重新绑定；`Esc` 取消录制；「恢复默认」一键还原。
- 方向键的网格导航固定为方向键，不可修改；`Esc` 关闭弹窗/预览固定生效。

## 8. 设置

设置窗口左侧分成「通用 / 外观 / 快捷键 / MCP / 插件 / 关于」六组，点击切换，右侧单独滚动。

| 项 | 说明 |
| --- | --- |
| 图库目录 | 显示当前路径，可修改（迁移） |
| 拖入图片时 | 移动（默认）/ 复制 |
| 拖出图片时 | 复制（默认）/ 移动 |
| 缩略图尺寸 | 小 / 中 / 大 |
| 主题 | 深色（默认）/ 浅色 / 跟随系统 |
| 简洁模式 | 开启后隐藏界面中的所有小字提示（尺寸/大小、说明文字等），画面更干净 |
| 动图预览 | 开启后网格中的 GIF / 动态 WebP 会直接播放（默认关闭，较大动图可能影响滚动流畅度） |
| 快捷键 | 查看并自定义快捷键 |

设置会持久化，重启后保持。

## 9. 数据与备份

- 图库目录内：`vault.db`（索引）、`images/`（原图）、`thumbs/`（缩略图）。
- 备份：直接复制整个图库目录即可；换电脑时把目录拷过去，首次启动选择该目录就能继续用。
- 启动时会自动校验：磁盘上缺失的图片会标灰并显示「缺失」；发现未入库的图片会提示一键导入。

## 10. 遇到问题

| 提示 | 处理 |
| --- | --- |
| 存储目录不可用 | 目录被移动/删除，或移动硬盘未插入；重新指定目录 |
| 文件正在被其他程序占用 | 关闭占用该文件的程序后重试；其余文件不受影响 |
| 磁盘空间不足 | 清理磁盘或换存储目录；不会产生半截文件 |
| 无法预览 | 图片损坏或过大；原文件仍可拖出 |
| 发现重复图片 | 选择跳过或仍然添加；内容完全一致才会提示 |
| 数据库损坏 | 软件会自动备份损坏库并重建索引，原图不受影响 |


## 11. MCP 接口（给 Agent 用）

1. 设置 → MCP 接口 → 打开开关（默认关闭）；首次开启会自动生成令牌。
2. 需要命令行接入的 Agent：点「复制 stdio 配置」，把 JSON 粘到 Agent 的 MCP 配置里即可（值指向本程序 exe 与 `--mcp-stdio`）。
3. 支持 URL 的 Agent：点「复制 HTTP 配置」，使用 `http://127.0.0.1:45871/mcp` 与 Bearer 令牌。
4. 修改端口后点「保存」立即生效；状态显示「运行中」即正常。
5. MCP 可以执行与界面一致的操作：导入/重命名/删除/导出图片、分类与标签管理、读写设置、扫描图库。
6. 服务只监听本机回环地址，不会联网；令牌请勿泄露。

## 12. 插件

1. 设置 → 插件 →「安装插件…」选择包含 `plugin.json` 的文件夹；也可以点「打开插件目录」把插件文件夹放进去。
2. 每个插件是一个文件夹：`plugin.json`（id/name/version/description/main）+ `main.js`。
3. 在设置里启用插件后，点「重新加载」生效；示例插件 `example-stats` 默认禁用，启用后工具栏会出现「图库统计」按钮。
4. 插件可以：添加工具栏按钮、调用图片/分类/标签/设置 API、弹出提示。插件是本地受信任代码，安装前请确认来源。
5. 在线插件源：设置 → 插件 → 在线插件源，填入你的 GitHub 仓库地址（形如 `https://fastly.jsdelivr.net/gh/用户名/仓库@main/plugins/index.json`），点「保存并刷新」后可直接安装；插件默认禁用，启用后点「重新加载」生效。
6. 之后的扩展功能都以插件形式提供，不需要改动主程序。
